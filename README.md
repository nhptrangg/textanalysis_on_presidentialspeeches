Project Overview

During my exchange semester at Amherst College, I had the opportunity to complete an independent project applying data science techniques learned in class while exploring a topic in greater depth. I chose Latent Dirichlet Allocation (LDA) as the focus of my project. This research is exploratory in nature, and I greatly enjoyed the process of designing, analyzing, and interpreting the results.

This project analyzes changes in George W. Bush’s presidential rhetoric using topic modeling. By applying LDA to a corpus of presidential speeches, the study identifies dominant themes and rhetorical patterns before and after a pivotal shift in public opinion. The pivot point is defined as the period when public disapproval surpassed public approval.

The analysis examines how the content and style of presidential communication evolve as public support declines, with particular attention to shifts in thematic emphasis and tone. Results are presented through data visualizations and an interactive R Shiny application that allows users to compare topics across time periods.
